# 🇸🇦 تطبيق "جاهز للطوارئ" | Emergency Ready
> **"تعلم. تدرب. كن جاهزًا."**  
> *"تعلم من خلال التجربة والمحاكاة، وليس القراءة فقط."*

تطبيق تعليمي وتفاعلي متكامل للسلامة العامة والاستعداد للطوارئ في المملكة العربية السعودية، مصمم ومبني ليعمل **بنسبة 100% بدون إنترنت (Offline-First)**، دون الحاجة لأي خوادم سحابية أو واجهات برمجة تطبيقات خارجية أو ذكاء اصطناعي، مما يجعله مثاليًا للجهات التعليمية والعسكرية والبيئات المغلقة والآمنة.

---

## 🌟 الميزات الرئيسية والمحاور الأساسية

1. **محرك المحاكاة التفاعلية (Interactive Simulation Engine):**
   - سيناريوهات طوارئ تفاعلية وواقعية غير دموية (Non-graphic).
   - توقيت زمني تنازلي محاكي لضغط الطوارئ (15 ثانية قابلة للتخصيص والتعطيل).
   - 4 خيارات قرار في كل محطة مع تقييم فوري للسلامة (قرار آمن وسليم ✅ مقابل قرار غير آمن ومحفوف بالمخاطر ⚠️).
   - تحليل وتفسير علمي مباشر لكل قرار لتعزيز الفهم والوعي الوقائي.

2. **شاشة النتائج وتقييم الأداء الرباعي (4-Dimension Performance Evaluation):**
   - النتيجة الإجمالية (Overall Score) من 100 مع تحديد المستوى.
   - قياس سرعة اتخاذ القرار (Decision Speed).
   - قياس معيار السلامة (Safety Standard).
   - قياس المعرفة بالإجراءات (Procedure Knowledge).
   - قياس كفاءة الاستجابة (Response Efficiency).
   - نقاط القوة المكتسبة، ما يحتاج إلى تحسين، والنصيحة التعليمية الذهبية.

3. **مؤشر درجة الجاهزية (Preparedness Score Index):**
   - احتساب درجة الجاهزية الشاملة ومتابعة التقدم في 8 مجالات طوارئ مختلفة:
     - 🔥 **الحرائق والإطفاء** (Fire Safety)
     - 🌧️ **السيول والأمطار الغزيرة** (Floods & Heavy Rain)
     - 🌡️ **الحرارة الشديدة وضربات الشمس** (Extreme Heat)
     - 🚗 **حوادث الطرق والسلامة المرورية** (Road Accidents)
     - 🏠 **السلامة المنزلية والغاز** (Home & Gas Safety)
     - 🏢 **الإخلاء والتدافع في المنشآت** (Evacuation & Crowd Safety)
     - ⚡ **المخاطر والصدمات الكهربائية** (Electrical Hazards)
     - 🧰 **الاستعداد للطوارئ وحقيبة الإسعاف** (Emergency Readiness & First Aid)

4. **نظام التحفيز والأوسمة (Gamification & Badges):**
   - نظام XP ومستويات تصاعدية (مبتدئ واعد ➔ مستجيب مدرب ➔ منقذ متقدم ➔ خبير إدارة الطوارئ ➔ بطل الجاهزية الوطني).
   - أوسمة إنجاز محلية تفتح عند تحقيق معايير معينة (أول محاكاة، مدافع الحريق، درع السيول، مستجيب سريع، بطل الجاهزية).
   - سجل تاريخي مفصل لجميع التدريبات السابقة مع الدرجات وتواريخ الإنجاز.

5. **نمط العائلة المحلي (Local Family Mode):**
   - إنشاء ملفات شخصية متعددة لأفراد الأسرة (الأب، الأم، الابن، الابنة، إلخ).
   - حفظ التقدم والأوسمة والدرجات بشكل مستقل لكل فرد في قاعدة البيانات المحلية.
   - لوحة ترتيب وجاهزية تنافسية لتعزيز ثقافة السلامة لجميع أفراد الأسرة.

6. **مركز المعرفة والأدلة التوضيحية (Knowledge Center):**
   - مكتبة تعليمية غير متصلة تحتوي على أدلة خطوة بخطوة (مثل: استخدام مطفأة الحريق بقاعدة PASS، الإنعاش القلبي الرئوي CPR، حقيبة الـ 72 ساعة، والوقاية من السيول).
   - قوائم واضحة لـ "ما يجب فعله" (Do's) و "ما يجب تجنبه" (Don'ts).
   - إمكانية حفظ المقالات في المفضلة (Bookmarks) والبحث السريع دون اتصال.

7. **دليل أرقام وإجراءات الطوارئ الرسمية (Emergency Directory):**
   - أرقام الطوارئ المعتمدة في المملكة (911، 998، 997، 996، 993، 933، 939، 199033، 937).
   - نسخ فوري للأرقام وموجه مباشر للاختصاصات.

8. **لوحة التحكم وإدارة المحتوى المحلية (Admin & Content Management Mode):**
   - دخول محمي برمز PIN محلي (الرمز الافتراضي: **`1234`**).
   - إنشاء وتعديل وحذف السيناريوهات ومحطات القرار والخيارات والتفسيرات.
   - إنشاء وتعديل المقالات التعليمية وأرقام الطوارئ.
   - إمكانية إعادة تعيين قاعدة البيانات واستعادة بيانات المصنع الافتراضية.

9. **الهوية والتصميم (Arabic-First & Premium UI):**
   - واجهة باللغة العربية أساسًا مع دعم كامل لاتجاه RTL والخطوط العربية.
   - دعم التبديل إلى اللغة الإنجليزية (LTR) بسلاسة.
   - دعم الوضع الليلي (Dark Mode) والوضع الفاتح (Light Mode).
   - تصميم بألوان الهوية السعودية (الأخضر السعودي الرسمي `#006C35`، الزمردي، والذهبي).

## 🏛️ البنية الهندسية غير المتصلة (Offline Architecture)

- **قاعدة البيانات:** SQLite محلية مدعومة عبر `sqflite` و `sqflite_common_ffi` لتعمل على نظام Windows Desktop والهواتف الذكية (Android / iOS) دون أي اتصال.
- **إدارة الحالة:** Provider Architecture.
- **البيانات المسبقة (Pre-seeded Data):** تتضمن 8 مجالات، 5 سيناريوهات مفصلة، أكثر من 16 محطة قرار، مقالات تفصيلية، وجميع أرقام الطوارئ الرسمية.

## 🚀 تشغيل التطبيق (How to Run)

### تشغيل التطبيق على Windows Desktop:
```bash
flutter run -d windows
```

### تشغيل التطبيق على متصفح الويب (Offline Local Web):
```bash
flutter run -d chrome
```

### تشغيل التطبيق على أجهزة Android:
```bash
flutter run -d android
```

### تشغيل الاختبارات الشاملة (Unit & Widget Tests):
```bash
flutter test
```

## 🔐 بيانات الدخول للإدارة (Admin Credentials)

- **الرمز السري (PIN):** `1234` (أو `911`)
- **الوصول:** من تبويب **الإعدادات** ➔ **لوحة التحكم والإشراف (Admin)**.
